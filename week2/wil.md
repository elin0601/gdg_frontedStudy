# 이번주

## React는 무엇인가?

### 1. React는 새로운 언어일까?

- React는 새로운 프로그래밍 언어가 아니고 JS와 함께 사용하고 UI를 도와주는 JS Library이다.
- *즉, React는 JS 대체 언어가 아닌 도구로 봐야 한다.*

### 2. 여기서 Library란?

- 개발에 필요한 모든 코드를 직접 작성하면 어렵고 시간이 오래 걸리기 때문에 필요한 부분을 찾아서 활용할 수 있게 도와주는 도구이다.
- 즉, 다른 프로그램에서 가져다 사용할 수 있도록 만들어놓은 **코드의 모음**이다.

## React는 UI를 만들기 위한 JS Library이다.

### React를 사용한다면 코드가 어떻게 달라질까?

- 우리가 보는 화면에는 구조가 있다. (영역이 나누어져 있다.)
- 코드에서도 화면의 구조가 보이기 시작한다.
- **React를 사용한다고 해서 코드가 무조건 단축되는 것이 아니다.**
